# Adhesion study

## Methods
Three independently prepared panels were measured for each formulation. Five indents were sampled within each panel. The enhanced formulation used a 40-micrometre coating; the reference formulation used a 20-micrometre coating.

## Results
The panel-mean adhesion values were 7.1, 7.5, and 7.3 MPa for the enhanced formulation and 5.8, 6.2, and 6.0 MPa for the reference formulation. The independently prepared unit was the panel (n = 3 per formulation); the five indents within each panel were subsamples. The enhanced formulation had higher observed panel-mean adhesion values than the reference formulation. Because coating thickness differed between formulations, this descriptive contrast does not isolate the effect of additive X.

## Conclusion
The observed formulation contrast motivates further study of adhesion under matched coating thickness.
