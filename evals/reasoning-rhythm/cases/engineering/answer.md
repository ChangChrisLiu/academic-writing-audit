We reconstruct contact events to determine when each finger first contacts the object relative to gripper motion. Network arrival times can differ from acquisition times because packet delays vary, so we use acquisition timestamps from the clock shared by the tactile records and robot-state log. We temporarily store incoming packets in a receive buffer and associate each tactile sample with the robot state at its acquisition timestamp. Contact timing is reported from these associations.
