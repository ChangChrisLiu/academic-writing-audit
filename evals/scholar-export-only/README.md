# Scholar-only BibTeX

Every accepted working BibTeX entry now comes directly from Google Scholar Cite → BibTeX for the verified work and version. This supersedes the historical allowance for local keys and supplemental DOI fields in canonical entries. Other publication metadata belongs in the identity ledger. The [reference guide](../../docs/reference-guide.md) and [LaTeX skill](../../skills/latex-bibliography-audit/SKILL.md) describe the current rule.

Two independent leaf verifiers searched for the journal version of Breiman’s *Random Forests*. Both used Chrome after the initial web reading route failed. Each selected Cite → BibTeX on its own Scholar result, retained the displayed text, and checked the full title, sole author, year and journal against the publisher. Their reports record separate retrievals from the same underlying Scholar and Springer sources. Each captured 195 bytes with key `breiman2001random` and SHA-256 `fd274f1b0c5702ad441dd136a83e82cbc68c964b453007acfa8e130197841cd3`. The publisher confirms a DOI that Scholar omits. Two subsequent fresh-context participants received separate local packets. Their requests, input hashes and criteria were frozen before those runs. The repair participant received the two identity reports, actual exports and an isolated copy of the earlier two-key project. It backed up the inputs, replaced the bibliography with the complete Scholar entry, migrated the main and included appendix citations, and recorded the DOI only in evidence. The resulting database is byte-identical to both captures. Offline Tectonic/BibTeX compiled the repaired project. Both citations printed [1], with one item in the bibliography. The fixture still contains a historical sentence about two keys, which the participant flagged. [Trial design](trial-design.json) · [Repair report and build evidence](repair-report.md)

The closed-packet participant received a legacy entry and a publication card with no traceable export. The legacy bytes happened to equal the live export withheld from that participant. It held the entry pending, preserved the original database and supplied no reconstructed BibTeX. This exercised missing provenance independently of metadata correctness. [Closed-packet report](closed/report.md)

The read-only checker compares each scoped working record with its indexed capture. Its eight executable tests cover exact copies, added DOI fields, edited capitalization and values, key changes, missing provenance, changed digests, collisions, duplicates and unsupported inputs. Local equality requires separate evidence for retrieval and publication identity. Non-entry material or unsupported syntax requires manual review. The skill trials used the policy text in this release apart from one blank line that split a Markdown table. The exact tested table is [retained](trial-identity-and-keys.txt).

Coverage is limited to this public article and these fixtures. The closed packet simulates unavailable export evidence. The tests did not audit a private manuscript bibliography or execute a Word refresh. The historical evaluations retain their original policies and results.
