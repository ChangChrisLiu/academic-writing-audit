# Word citation audit

Case A has two incorrect cached Vale citation displays and one uncited entry in the main References section. Case B has no identity or coverage defect under the supplied author rules; its requested prose typo has been corrected in `revised-b.docx`. This was an offline audit of the supplied materials. Publication authenticity and whether a work supports a sentence were not checked. No external service, native Word session, citation-manager refresh, or native application save/reopen was used.

## Scope, style, and evidence

For A and B, the controlling requirement is the custom author–year rule in `inputs/request.md`: identical authors in the same year receive suffixes assigned by title alphabetization; main References contains cited works, including notes and captions; Further reading may contain uncited recommendations. The request does not prescribe the rest of a named style manual, global bibliography ordering, or other punctuation conventions.

Both DOCX packages store `StyleName="APA"`, `Version="6"`, and `SelectedStyle="/APASixthEditionOfficeOnline.xsl"` in `customXml/item1.xml`. These are stored configuration labels suggesting an APA sixth-edition stylesheet. They do not establish the active style in an open Word application or prove that the cached displays were generated by that stylesheet. The author’s explicit rules govern this audit; full APA compliance is not claimed. Case C’s required and selected styles are unavailable; the A/B-specific rule is not silently extended to it.

I inspected all supplied DOCX package parts, main-document text, caption and cross-reference fields, the footnotes part and note anchor, source records, package relationships, and revision markup. Each document contains 12 main-document paragraphs, one substantive footnote (ID 1), and a single caption. The two additional footnote elements are system separators, not citations. There are no table, text-box, drawing-text, embedded-object, alternate-content import, header/footer, endnote, comment, or appendix stories containing additional content in these packages. No tracked insertions, deletions, moved text, or property-change markup was found, so there is no alternate revision inventory to combine or accept. All internal relationship targets resolve.

A/B “displayed” text below means the saved field result found in OOXML, not a newly refreshed Word display. Case B’s revised display was also checked in the bundled LibreOffice render. Case A was neither edited nor rendered/refreshed.
