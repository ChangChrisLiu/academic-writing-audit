Corrected paragraph:

“All variants use the same classifier architecture, optimizer, batch size, and held-out evaluation set, with 8,000 optimizer updates per fit. Selected normalizes a smooth nonlinear function of confidence and error-type features, then applies source multipliers. It fits six coefficient configurations and chooses one by validation accuracy. Fixed map uses the same nonlinear formula with preset coefficients and source multipliers in one fit without validation selection. Threshold instead assigns one of two constant weights according to a confidence threshold and applies preset source multipliers, also in one fit. These three variants exclude 2,000 routine clips failing the quality gate, leaving 28,000 eligible clips. Uniform assigns weight 1 to all 30,000 clips and uses one fit. No feedback uses the chosen Selected coefficients, removes all 6,000 operator-corrected clips, and fits once on the 22,000 quality-passing routine clips without retuning. Source tags remain on those clips. This variant examines training without corrected examples; it does not isolate the effect of feedback annotations. Budgets match per fit, but Selected requires six candidate fits, and eligible data differ across variants. Total runtime and effective weighted exposure were not recorded.”
