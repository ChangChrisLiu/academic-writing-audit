# Matching and coverage decisions

| Form or situation | Check |
| --- | --- |
| Numeric `[2–4, 7]` | Resolve 2, 3, 4, and 7, using the style's numbering and ordering rules. |
| Narrative `Lee (2021)` | Count as a citation even outside a parenthesized cluster. |
| `Lee et al., 2021` maps to two entries | Use full author identities and the actual style's disambiguation rules; do not choose arbitrarily. |
| `2021a` and `2021b` | Check that labels consistently identify the intended works; suffix assignment can change after refreshing the bibliography. |
| Corporate author or abbreviation | Verify the style's introduced abbreviation and matching full organization name. |
| Superscript note marker | Inspect the note. A note number may contain several sources and need not equal a bibliography number. |
| Citation in a caption, table, text box, or appendix | Include in the inspected scope; do not classify its reference as uncited because it is absent from body paragraphs. |
| Further reading allowed by the venue | Report uncited entries as intentional when evidenced, separate from the cited reference list. |
| Plain-text export from Word | Audit visible identity and formatting; qualify native-field, tracked-change, and omitted-region coverage. |
| Citation manager fields with displayed text inconsistent with field identity | Report the mismatch; repair through the manager and inspect after refresh. |

For native DOCX inspection, use a field-aware document tool where possible. If inspecting the package, include the relevant document parts and relationships, tables, text boxes, footnotes/endnotes, and revision markup; a `document.xml` paragraph-only text extractor is not proof of full-document coverage. Never modify package XML merely to replace displayed citation text while leaving incompatible field data.

A useful report separates style evidence, occurrence-to-entry findings, entry-to-occurrence findings, identity duplicates, field integrity, and unchecked regions. Avoid reporting a universal “all citations verified” when only formatting or visible text was inspected.
