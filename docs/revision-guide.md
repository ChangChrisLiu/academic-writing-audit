# 专业角色、逻辑审查与修改前后对照

[指南索引](README.md) · [中文说明](../README.zh-CN.md) · [Home](../README.md)

写作审查首先要判断研究是否回答了自己的问题，然后才判断表达是否清楚。把 agent 称为 reviewer 或 editor 并不会自动提供专业能力。需要明确它面对哪个研究设计、要作出什么判断、能读取哪些证据，以及判断依据从哪里来。

## 按问题选择专业视角

完整审查入口 [academic-writing-audit](../skills/academic-writing-audit/SKILL.md) 包含[角色与逻辑预期规则](../skills/academic-writing-audit/references/roles-and-expectations.md)。角色范围由学科、子方向、研究设计、读者和具体任务共同确定。

| 视角 | 应当解决的问题 |
| --- | --- |
| Scientific reviewer | 文章提出的问题是否被当前论证和证据回答，结论有没有超出支持范围？ |
| Methodological specialist | 关键判断所依赖的实验比较、因果识别、证明步骤或质性解释是否成立？ |
| Scholarly editor | 信息顺序、定义、术语、句子和段落是否便于目标读者理解？ |
| First-time domain reader | 不知道项目历史的同行，能否跟上对象、条件和推理的转换？ |
| Revision checker | 修改解决了原问题吗，有没有同时丢掉有效信息或引入新错误？ |

这些视角可以由一个 agent 分轮完成，不要求每次启动五个 agent。独立复核适合重要或有争议的判断，但仍需用户授权的任务范围。给独立 agent 当前稿、证据和明确问题，尽量先不提供上一轮结论。分歧回到原文和证据解决，不以票数决定。

研究设计与学科名称同样重要。临床观察性研究的关联结论需要检查混杂和目标量，数学保证需要检查假设与量词，反思性主题分析需要检查分析立场与解释依据。不能把统计显著性、消融实验、编码一致性或统一章节模板当作所有文章的必要条件。

## 把逻辑预期讲具体

每个重要问题都要说明它应当建立什么、为什么需要建立这一点、现在实际建立了什么，以及两者还差在哪里。预期可以来自研究问题、作者保留的主张、真实审稿意见或明确的格式要求。由 agent 推断的读者需要应当标明，不能冒充审稿人的意图或期刊规定。

例如，读者要判断一种机器人流程能否完成检测。正文只说明到达了目标位置，就还没有回答是否取得可用图像。如果实际成功定义包括这两个步骤，编辑需要保留完整定义和分母。回复信说“已经澄清”不能代替正文里的操作解释。

相反，若文章只报告特定条件下的系统表现，不能因为某个 reviewer 期待独立机制证明，就自动把新增实验定为必做。应先判断这个要求是否对应文章保留的主张，再决定补充说明、收窄结论、提供已有证据或说明尚未解决的问题。

## 检查压缩是否丢掉科学含义

新增的 [revision-integrity-audit](../skills/revision-integrity-audit/SKILL.md) 专门比较修改前后。它分开判断修改目标是否实现，以及有效论证和信息是否保留。两项都需要检查，不能只看字数、相似度或文字是否流畅。

比较关注研究动机、方法为何对应问题、不同部分的作用、定义与条件、比较对象、结果口径、证据连接、解释与边界。具体检查范围取决于改动，不要求为每个句子填一张表。补入的新词也要审查，例如 optimal、uniform 或 causal 可能悄悄加强原有结论。

旧稿不是标准答案。有依据的事实纠正应该保留，重复的保证可以删，已经核实的参数表可以移到附录。定义和关键范围仍需在读者使用它们的位置可理解。若附录没有提供，只能说迁移未核实，不能断言内容安全保留或已经丢失。

发现问题时恢复缺少的含义，保留新稿已经取得的改善。不要为了完整性复制回整段旧稿，也不要把正文改成回应 reviewer 的口吻。源文件比较、编译和版面检查是不同的验证范围。

## 可以直接使用的请求

```text
使用 $academic-writing-audit 审查这篇稿件。
先根据研究子方向、研究设计和目标读者确定 reviewer 与 editor 的判断范围。
逐项说明关键部分应当建立什么、依据是什么、当前实际建立了什么。
区分科学问题、解释缺口、已经解决的问题和可选表达建议。
先只审查，不改原稿。
```

```text
使用 $revision-integrity-audit 比较这两个版本。
检查修改是否解决指定问题，以及压缩是否丢掉动机、条件、定义、
证据连接或结果解释。保留有效纠错、正常专业术语和合理压缩。
只指出有后果的差异与最小修复，不恢复整段旧稿，不改文件。
```
