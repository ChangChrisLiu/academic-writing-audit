# 先理解研究，再写成论文

[research-manuscript-writing](../skills/research-manuscript-writing/SKILL.md) 负责从研究材料起草或重组章节。它先理解研究方向、具体问题、已有工作、尚未解决的困难、方法为何适合这个问题，以及证据实际支持什么。只有题目或方法名称时，不能用泛泛的背景、猜测的新颖性和虚构结果补成一篇论文。缺少决定主线的信息，就指出具体缺口；已经有依据的部分可以继续。

## 摘要保留问题到结果的推进

默认从具体任务及其要求写起，交代现有路径的不足，再说明可利用的信息或思路与仍未解决的难点，随后介绍本文的科学贡献和最关键的结果。方法细节只保留解释核心思路所需的部分。结果要带有必要的研究范围，不能用一个局部指标概括未经评估的完整任务。

这里借鉴的是实际写作中形成的逻辑，不是固定六句话、固定词数或逐句填空。摘要不应变成模块、数据和指标的清单。理论工作可以落到假设与定理，质性研究可以落到研究场景与核心解释。期刊要求结构式摘要时，保留规定格式。

## 引言逐步收窄

引言从与问题直接相关的大方向开始，说明这个方向已经做到了什么，再推进到具体 gap、motivation 和 contribution。每一步都要为下一步提供理由。gap 说明尚未解决什么，motivation 解释为什么本文采取的科学思路适合解决它，二者不能只是换词重复。

开头无需扩展到与研究无关的宏大背景。贡献应在这条论证链中自然出现，默认写成连贯段落。只有作者或投稿格式要求时才列贡献清单。不能为了凑齐倒三角结构，替已有文献编造缺陷或把每个实现细节都提升为贡献。

## 文献综述沿着引言展开

从引言已经形成的问题链中选择两到三个相互关联的研究方向，讲清已有工作研究了什么、如何处理、得到什么结果，以及不同工作之间怎样推进或衔接。方向之间可以重叠，来源不足时也不必硬凑第三类。

默认不按传统方法、现代方法和混合方法之类的标签分类，不写成一篇论文一句话的目录，也不在每段末尾对比本文优点。综述把已有研究讲清楚，本文的定位放在引言或讨论中。文献之间有意义的区别仍然可以解释。显式的新颖性审查或作者要求的本文对比属于另一项明确任务。

篇幅较长时可以用有实质含义的小节标题帮助阅读。小节不是分类清单，段落也不需要不断加粗小标题。引文必须支持相邻命题，摘要或摘录没有提到某项能力，不等于原研究没有这项能力。

## 方法按理解所需的顺序展开

先交代对象、目的和必要假设，再顺着操作或分析依赖解释输入、处理、输出及下一步用途。概念在需要时定义，后面稳定使用。概览、公式和算法可以承担不同任务，但不应逐行重复相同内容。

删去反复强调严谨、可靠或公平的保证，保留真正影响方法含义的筛选条件、失败分支和适用边界。正文必须让人明白操作本身，再把详细参数、推导或协议放入确有内容的附录。质性分析和理论证明按其真实分析过程组织，不强行改写成工程流水线。

## 结果与结尾服从学科和研究设计

定量研究可以围绕主要问题、估计及其不确定性展开。工程实验需要区分主比较和用于解释原因的诊断。质性研究需要分析命题、材料支持、解释与反例，不能把主题写成人群发生率。理论研究按假设、命题、证明和推论推进。混合方法还要解释不同证据之间的分歧。具体段落顺序以研究设计和期刊结构为准，而非只凭学科名称套模板。

Results 与 Discussion 分开时，各自承担合适的观察和解释任务；合并时也要让读者看清二者。不要重复每一个表格数字，也不要给每个结果机械追加免责声明。

局限性说明哪个条件限制了哪一种推断或应用，以及这对理解结果有什么影响。它可以放在讨论中，也可以单设一节。结论回到研究问题，给出已经支持的答案和适当意义，不逐节复述全文，不增加新结果，也不自动附上一串未来工作。

## LaTeX 与 Word 保持同一套论证

LaTeX 保留既有文档类、章节层级、引用命令、文献键、公式和交叉引用，不用 Markdown 语法代替。Word 的可粘贴文字使用普通标题与段落，实际文档使用原生样式，并保留引文管理器字段、书签和修订记录。具体规则见[格式与交付](../skills/research-manuscript-writing/references/latex-and-word.md)。源文件检查、实际编译和版面检查分别报告。

整体追求 concise 的连贯论述。清楚而简洁的判断标准是每句话是否承担必要任务、是否与前后衔接，而不是字数越少越好。专业术语、科学条件、独立图注中的必要重述和正式算法格式都可以保留。写作默认不用解释性冒号或句中破折号，同时保留复合词连字符和技术符号。

## 使用示例

```text
Use $research-manuscript-writing with these study materials.
Understand the question, motivation, contribution, and evidence before drafting.
Write the requested sections as a concise, connected argument.
Use an introduction funnel and related literature threads derived from it.
Follow the supplied discipline, section conventions, and LaTeX or Word format.
Identify decisive missing facts instead of filling them with generic prose.
```
